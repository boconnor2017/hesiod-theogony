# Instructions for Populating lab_spec.json
Download or copy `json_lib/lab_spec.json` from [Github](https://github.com/boconnor2017/hesiod-theogony/blob/main/json_lib/lab_spec.json). Store the file locally (recommended: use Visual Studio Code or equivalent to manage changes). When the file is ready for use in a given module, paste the contents to `conf/lab_spec.json` on Hesiod Main using a `vi` editor. Update this file as often as is needed to resolve failures.

# Overview of lab_spec.json
The structure of the json file is as follows.

| Key            | JSON Query                    | Description |
|----------------|-------------------------------|----------------------------------------------------------------------------------|
| Authentication | `lab_spec["authentication"]   | Contains the administrative passwords used to connect to various lab components. |
| Domain         | `lab_spec["domain"]           | Contains the specs for deploying and connecting to a Domain Name Server.         |
